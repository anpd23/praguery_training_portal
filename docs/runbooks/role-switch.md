# Runbook: switch teammate (no PIN)

Academy v1 uses role tap on a shared iPad. There is no PIN pad.

1. Current teammate opens **Settings** → **Switch teammate** (or **Sign out** on the landing screen).
2. Next teammate taps their role on the landing screen.
3. Confirm the home header shows their name and the right working location.
4. If the wrong location is showing, change **Working location** in Settings before running a checklist.

If someone signs in as the wrong role, switch teammate immediately. Do not complete a food-safety checklist under another person’s name.
