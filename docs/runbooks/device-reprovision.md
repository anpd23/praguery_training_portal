# Runbook: device re-provision

1. Sign out every teammate (**Switch teammate** in Settings, or Sign out on the landing screen).
2. If the iPad must be wiped: Settings → Erase, restore, join location Wi-Fi.
3. Open the Academy URL in Safari. Add to Home Screen.
4. Optional: Guided Access so the device stays on Academy.
5. Tap the supervisor or manager role. Tap **Sync now**.
6. Confirm the offline banner appears when Wi-Fi is disabled and a checklist still saves.
